# Dataset setup

Download the BigMart Sales training data from:

https://www.kaggle.com/datasets/mustang007/big-mart-sales-data

Place the training CSV in this directory with this exact name:

```text
retail-sales-prediction/data/Train.csv
```

Expected shape: 8,523 rows × 12 columns. The file is intentionally excluded from version control to avoid redistributing third-party data.
