# Dataset setup

Download the **100,000 UK Used Car Data Set** from:

https://www.kaggle.com/datasets/adityadesai13/used-car-dataset-ford-and-mercedes

Extract only `audi.csv` and place it in this directory:

```text
car-price-prediction/data/audi.csv
```

Expected shape: 10,668 rows × 9 columns. The CSV is intentionally not committed to this repository; this keeps the source attribution clear and avoids redistributing third-party data.
